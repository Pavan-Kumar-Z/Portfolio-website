# 🌐 Pavan Kumar – Portfolio Website

### A modern, responsive dark-themed developer portfolio built with **HTML**, **CSS**, and **JavaScript**, showcasing my skills in **Full-Stack Development** and **AI/ML Systems**.

---

## 🚀 Overview

This portfolio website is designed to highlight my projects, technical expertise, and professional experience as a **Full-Stack Engineer** specializing in **AI and Machine Learning**.

It features smooth navigation, responsive layouts, interactive hover effects, and a clean dark aesthetic inspired by modern developer portfolios.

All sections are fully customizable — making it ideal for both personal presentation and public hosting on platforms like **Netlify** or **GitHub Pages**.

---

## 🧩 Features

✅ **Fully Responsive Layout** – Works seamlessly on desktops, tablets, and mobile devices.
✅ **Dark Theme Design** – Elegant and consistent look with balanced contrast and color gradients.
✅ **Single Page Navigation** – Smooth scroll navigation to sections (Home, Projects, Experience, Contact).
✅ **Project Cards** – Modern vertical grid cards with live demo & GitHub links.
✅ **Skill Icons Section** – Interactive logos for core technologies.
✅ **Contact Section** – Displays email, GitHub, and LinkedIn links (to be added next).
✅ **SEO-Friendly** – Includes meta tags and descriptive titles for better discoverability.
✅ **Deployed for Free** – Hosted using **Netlify** (but supports GitHub Pages or Vercel too).

## ⚙️ Setup & Usage

1. **Clone the repository**

   ```bash
   git clone https://github.com/Pavan-Kumar-Z/portfolio.git
   cd portfolio
   ```

2. **Open locally**

   ```bash
   # If you have Python installed
   python -m http.server 8000
   ```

   Then visit: [http://localhost:8000](http://localhost:8000)

3. **Deploy**

   * **Option 1 – Netlify:** Drag & drop the folder into Netlify dashboard.
   * **Option 2 – GitHub Pages:**
     Go to repo → *Settings → Pages* → Choose branch `main` and `/root`.
   * **Option 3 – Vercel:** Import your GitHub repo directly.
